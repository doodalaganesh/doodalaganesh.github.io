# Dudala Ganesh — Portfolio

A responsive personal portfolio website for GitHub Pages.

## Files

- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — mobile menu and current year
- `assets/Dudala_Ganesh_Resume.pdf` — resume from the uploaded CV

## Publish for free with GitHub Pages

1. Create/login to GitHub.
2. Create a **public** repository named exactly:
   `YOUR-GITHUB-USERNAME.github.io`
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Wait a few minutes.
8. Your public website will be:
   `https://YOUR-GITHUB-USERNAME.github.io`

Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username.

## Before publishing

Check that the public contact details in the resume are okay to expose. The site currently uses the email and LinkedIn information from the supplied CV.
